The Problem

Healthcare access in Kenya is unevenly distributed

Resource maldistribution

Most of the 9,736 facilities are dispensaries and health centres. Only a few are county referral hospitals or higher, mostly in a handful of urban counties.

Patients don't know where to go

Without guidance, many people go to the nearest facility, even when it cannot treat them.

No identity stored. Only a rounded location is logged. Never your name, phone number or exact address.
Real-time rate limiting. Requests are limited on the server to stop abuse.

Why Was the Final Model Chosen?

Final Model Configuration
Read from the trained model.

Hyperparameter Tuning

The main setting, regularisation strength (C), was checked from 0.1 to 100 and the default (C=1) scored best. Other model types (Naive Bayes, SVM, neural network, simple ensembles) scored within about half a point of it, or lower, so the defaults were kept. A full grid search was not run. These scores come from augmented data and are probably optimistic.

Dataset & Features

This project uses two related datasets: a real published dataset (itachi9604's Kaggle "Disease Symptom Prediction," 4,920 rows) and an augmented training dataset built from it (6,150 rows) that adds realistic symptom overlap and reporting noise. The model deployed here is trained on the augmented dataset — see "Robustness & Data Quality" below for why that distinction matters.

Robustness & Data Quality

High test accuracy alone doesn't prove real-world clinical performance. These checks were run on the raw Kaggle dataset to test that directly.
